# Иконка ярлыка

Картинка **сгенерирована нами** — MiniMax image-01 (тогда же готовился ярлык для версии
на Raspberry Pi 4). Это не арт, выдранный из игры, поэтому иконка и лежит в репозитории
вместе с ярлыком.

## Состав

| Файл | Что это |
|---|---|
| `source/worms-armageddon-raw-1024.png` | исходная генерация 1024×1024 — широкая сцена: червяк в каске с пушкой на звёздном фоне |
| `worms-armageddon-512.png` | рабочая иконка (голова червяка в каске на голубом фоне) — её же читает карусель рабочего стола |
| `worms-armageddon-256.png`, `-128.png`, `-64.png`, `-48.png` | та же иконка меньших размеров: меню, панель, список окон |
| `worms-armageddon.desktop` | ярлык для рабочего стола и меню (раздел «Игры», категория `Game`) |

## Как ставить

Шаг 8 в [../INSTALL.md](../INSTALL.md): иконки копируются в `~/.local/share/icons/worms/`,
ярлык — в `~/.local/share/applications/` и `~/Desktop/`.

## Если нужен другой размер

Из исходника (или из 512) любым конвертером:

```bash
python3 - <<'PY'
from PIL import Image
im = Image.open("worms-armageddon-512.png")
im.resize((96, 96), Image.LANCZOS).save("worms-armageddon-96.png")
PY
```
